# Java Implementation Practice

Java 문법을 실제 코드에 적용하고, 객체지향 설계와 예외 처리, 테스트 작성 능력을 기르기 위한 구현 연습 저장소입니다.

## 진행 방식

요구사항 분석 → 객체 역할 분리 → 기능 구현 → 테스트 작성 순서로 진행합니다.

## 사용 기술

`Java` · `Gradle` · `JUnit 5` · `AssertJ`

## 1. 회원가입 정보 검증기

### 주요 기능

* 아이디, 비밀번호, 이름 검증
* 올바른 회원 정보로 사용자 생성
* 잘못된 입력에 `IllegalArgumentException` 발생

### 검증 규칙

* 아이디: 5~12자, 영문 소문자와 숫자만 허용
* 비밀번호: 8~20자, 영문자와 숫자를 각각 하나 이상 포함
* 이름: 빈 값과 공백만 있는 값은 허용하지 않음
* 모든 입력에 공백을 허용하지 않음

## 2. 장바구니·할인 계산

### 주요 기능

* 여러 상품을 장바구니에 추가
* 상품별 금액과 전체 금액 계산
* 수량·총액·회원 할인 적용
* 할인 내역과 최종 결제 금액 계산
* 잘못된 상품 정보 예외 처리

### 할인 규칙

1. 같은 상품을 3개 이상 구매하면 해당 상품 금액의 10% 할인
2. 수량 할인 후 금액이 100,000원 이상이면 5% 추가 할인
3. 회원이면 마지막 금액에서 3% 추가 할인
4. 할인 계산 중 발생한 소수점 이하는 버림

## 3. 카드 게임

### 주요 기능

* 숫자와 문양을 조합해 카드 52장 생성
* 생성된 카드 덱 무작위 섞기
* 덱에서 카드를 한 장씩 뽑기
* 플레이어에게 카드 지급
* 플레이어가 가진 카드의 숫자 합계 계산

### 객체별 역할

* `Card`: 카드의 숫자와 문양 보관
* `Suit`: 카드 문양 관리
* `Deck`: 카드 생성, 섞기, 뽑기
* `Player`: 플레이어의 이름과 받은 카드 관리
* `CardMain`: 카드 게임 실행
